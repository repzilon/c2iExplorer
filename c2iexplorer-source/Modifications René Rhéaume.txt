À propos de c2iExplorer
-----------------------
c2iExplorer est un explorateur de projet d'abord conçu par Richard Clark pour Visual Basic 6.0. Il permet de remplacer l'explorateur de projet fourni avec VB par une version permettant d'afficher, de filtrer et d'atteindre les membres d'un fichier de code, que ce soit une feuille, classe ou module. N'ayant que la version 5.0 (avec Service Pack 3), je ne pouvais pas en profiter avant que ce complément ne soit en source ouvert. J'ai alors décidé de le porter à VB5, puis de l'héberger sur sourceforge.net.

Après une carrière en informatique de 2005 à 2022 qui me laissa un goût très amer, j'entrepris un retour aux études de trois ans, dans un autre domaine. Cette première carrière m'a fait perdre beaucoup de choses, dont mes accès à Sourceforge. En 2025, par intérêt pour la rétro-informatique, je décide de remonter le projet sur Github depuis les archives restées sur Sourceforge depuis tout ce temps. Et de corriger les anomalies qui se présenteraient.

Modifications au code source
----------------------------
Voici les changements depuis la version 1.60.159, parue en 2005 (il y a 20 ans !) :
    - tentative de réparation de l'erreur 339 au démarrage lorsque les contôles communs sont mal enregistrés;
    - remplacé le formulaire s'affichant lorsque c2iExplorer.ini est absent par une boîte de message standard, cela semble réduire la taille de seulement 2 Ko;
    - dans le code source, converti des archives et documents en formats plus modernes mais toujours lisibles avec des logiciels disponibles pour Windows 98.
J'indique Beta car il y a des corrections (encore) à apporter.
Veuillez rapporter les bogues en allant à https://github.com/repzilon/c2iExplorer/issues, puis en cliquant sur le bouton «New issue».
Le code source peut être compilé facilement sous VB5 ou VB6 en utilisant le fichier projet approprié.

Configuration logicielle requise
--------------------------------
Vous avez besoin de :
    - Windows 32 bits (95, 98, 98 SE, Me, NT4, 2000);
    - Visual Basic 5.0 SP3 (compilé avec et il y a eu des modifications au niveau des composants ActiveX) ou Visual Basic 6.0 (compilé avec la version SP4, quand je pouvais);
    - une version récente de la bibliothèque de contrôles communs de Windows (Internet Explorer 5 vous en fournit une récente);
    - le contrôle ActiveX des contrôles communs de Windows version 6.0 ou ultérieure;
    - DAO (Data Access Objects) 3.5 : Microsoft Office 97 (Access) et VB5 Pro ou Entreprise vous l'installe que si vous le demandez dans leur programme d'installation respectif;
    - pour la fonction d'impression, Internet Explorer 5.0 ou plus récent, la suite Mozilla ou Firefox sont recommandés.

VBAddin.ini
-----------
Au cas où le programme d'installation n'installerait pas correctement le complément, ajoutez le texte suivant dans la section [Add-Ins32] du fichier vbaddin.ini, qui se trouve dans le dossier de Windows :

c2iexplorer.Connectc2iExplorer=1

About c2iExplorer
-----------------
c2iExplorer is a project explorer first designed by Richard Clark for Visual Basic 6.0. It replaces the project explorer included with VB with a version that allows you to display, filter, and navigate to the members of a code file, whether it's a form, class, or module. Having only version 5.0 (with Service Pack 3), I couldn't use it until this add-in was open sourced. I then decided to port it to VB5 and then host it on sourceforge.net.

After a career in information technology from 2005 to 2022 that left me with a bitter taste, I undertook a three-year return to studies in another field. That first career cost me a lot of things, including my access to Sourceforge. In 2025, out of an interest in retro-computing, I decided to re-upload the project to Github from the archives that had remained on Sourceforge all this time. And to correct any anomalies that may arise.

Modifications to source code
----------------------------
Here are the changes since version 1.60.159, released in 2005 (20 years ago!):
    - attempted to fix the error 339 at startup when common controls are incorrectly registered;
    - replaced the form displayed when c2iExplorer.ini is missing with a standard message box, this appears to reduce the file size by only 2 KB;
    - inside source code, converted archives and documents to more modern formats that are still readable with software available for Windows 98.
I wrote Beta because there are still bugs in it.
Report them to https://github.com/repzilon/c2iExplorer/issues, then click the "New issue" link.
Source code can be easily compiled in VB5 or VB6 using the according project file.

Required software configuration
-------------------------------
You need:
    - 32 bits Windows (95, 98, 98 SE, Me, NT4, 2000);
    - Visual Basic 5.0 SP3 (compiled with it and SP3 contains modifications about ActiveX components) or Visual Basic 6.0 (compiled with SP4 applied, when I was able to);
    - Recent version of the Windows common controls DLL (install Internet Explorer 5 or newer);
    - Windows common controls ActiveX control version 6.0 or better;
    - DAO (Data Access Objects) 3.5 : Microsoft Office 97 (Access) and VB5 Pro or Enterprise installation programs can let you install it in a custom install;
    - For project report function, Internet Explorer 5.0 or newer, the Mozilla suite or Firefox are recommended.

VBAddin.ini
-----------
In case of installation program does not install correctly the add-in, add this line in the [Add-Ins32] section in file vbaddin.ini, which is in Windows directory:

c2iexplorer.Connectc2iExplorer=1

Future improvements
-------------------
    - correct bugs;
    - reduce add-in size (now 418 kiB);
    - write documentation.
